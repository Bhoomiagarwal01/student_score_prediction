# Student Score Prediction

This project predicts student exam scores using Linear Regression based on study hours.

## 📌 Problem Statement
The goal is to build a machine learning model that can estimate a student's score based on the number of hours they studied.

## ⚙️ Approach
- Used **Linear Regression**
- Dataset contains:
  - Study Hours (input feature)
  - Scores (target variable)
- Model trained using `scikit-learn`

## 📊 Model Workflow
1. Import dataset
2. Split into training and testing sets
3. Train Linear Regression model
4. Predict scores
5. Evaluate performance
